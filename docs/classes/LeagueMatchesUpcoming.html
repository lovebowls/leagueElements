    Class LeagueMatchesUpcoming

    Custom element to display upcoming fixtures with paging and optional date filtering.

    Element

    league-matches-upcoming

    Attr

    data - JSON stringified array of match objects

    Attr

    [filter-date] - ISO date string (YYYY-MM-DD) to filter fixtures by date

    Attr

    [is-mobile] - Whether to use mobile styles

    Attr

    [team-mapping] - JSON stringified array of {value, label} objects mapping team values to display names

    Emits 'league-matches-upcoming-event' with detail { type: 'matchClick', match }
